Part IV: Non-Functional Requirements (NFRs)
Security:
The contract must use ReentrancyGuard on all withdrawal functions.
All administrative functions must be protected by AccessControl.
The Oracle's signature verification must be robust (ECDSA.recover).
The contract must be Pausable in case of emergency.
Requirement: A full, third-party security audit is mandatory before mainnet deployment.
Performance:
Frontend dashboard load time must be < 3 seconds, necessitating the off-chain cache.
All smart contract transactions must be optimized for gas efficiency.
Cost Optimization:
The architecture must leverage Hedera's low fees. HCS is used for low-cost timestamping, and HSCS fees are minimal for votes.
Proof data must be stored off-chain (IPFS) to avoid prohibitive on-chain storage costs.
Usability:
The wallet connection process must be seamless for HashPack users.
All errors (failed transactions, out-of-gas, etc.) must be caught and presented to the user in a human-readable format.
Reliability:
The off-chain Oracle service must have > 99.9% uptime. It is a single point of failure for goal finalization in the MVP.
